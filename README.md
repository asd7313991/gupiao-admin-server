# 关于

本项目是 [art-design-pro-edge](https://github.com/ChnMig/art-design-pro-edge) 的后端服务。
配合前端可以做到开箱即用, 但是具体的业务功能需要自己开发.

## 项目特点

- 项目的95%代码由 `github copilot` 辅助编写

### A股榜单与指数更新

- A股采集按证券代码稳定分页，最多4页并发，先校验完整快照，再以单个事务批量发布价格、涨跌幅、成交量/额、换手率与源端 `quote_at`。避免按实时涨幅分页产生重复/遗漏，或只发布部分页面后造成新旧价格混排行；失败保留上一轮缓存并记录错误，不伪造新报价时间。同步不覆盖已有证券启停状态。配置的最大条数仍生效，要覆盖全市场应保留默认10000条。
- 定时任务每10秒检查是否到达后台配置的采集间隔；默认盘中60秒、盘外600秒，实际更新还包括采集耗时。缺失的旧配置采用默认A股时段和同步参数；明确关闭自动同步时保持关闭，无效配置记录告警。交易时段与全天模拟交易开关不改变真实市场的报价更新。
- 东方财富全市场采集失败时记录告警，按本地已收录A股清单批量读取腾讯备用价格、涨跌幅、成交量/额、换手率和原始时间，每批100只、最多4批并发，同样统一发布；备用源不负责新增尚未收录的新股。单只无有效报价明确标记 `tencent/unavailable`，不冒用旧价参加榜单；搜索仍可找到该证券，但显示无有效报价。主备都失败时返回错误并保留上一轮缓存，前端按原始时间提示延迟。
- 移动端每5秒检查指数及榜单，榜单仍按全市场已发布快照排序/分页。指数改用腾讯完整报价，验证代码、有限数值与原始报价时间，缺失任一指数时明确报错。行情接口返回禁止缓存响应头，公开源本身仍可能延迟；午休、收盘、停牌和节假日不保证报价变化。
- 定向测试：`go test ./api/app/v1/private/admin/platform/stock ./api/app/v1/open/mobile ./cron`。设置 `MARKET_QUOTE_LIVE_TEST=1` 可运行只读公开全市场采集验证，不写账户、证券或成交数据库。

### 人民币与港币资金兑换

- 数据库迁移新增客户 `hkd_balance`（初始为零）与 `currency_exchanges` 成交记录表；原 `balance` 始终是人民币，`strategy_balance` 不作港币账户使用。部署新接口前先执行现有迁移命令 `go run . --migrate`。
- 客户认证接口 `GET /api/v1/open/mobile/finance/exchange` 返回独立 CNY/HKD 余额、汇率及配置更新时间；`POST` 同路径执行兑换，参数为 `request_id`（16–64 位字母/数字/连字符）、`from_currency`（CNY/HKD）、`amount`、`rate`、`trade_pin`。
- 汇率取后台系统设置 `links.hkdRate`，含义为 **1 HKD = X CNY**，最多八位小数，合法范围 0.00000001–100。缺失或无效时拒绝兑换，不采用默认价格；提交汇率不同于当前配置时必须刷新后再次确认。时间是后台配置更新时间，不是实时外汇报价时间。
- 已实名认证、账户及资金状态正常且交易密码正确才能兑换；确认后即时到账，不额外收兑换费。兑出金额 0.01–5,000,000，最多两位小数；兑入按精确十进制计算并向下保留到分，过小及超过账户限制的兑入金额会拒绝。
- 事务内锁客户行，原子更新两个余额、成交汇率快照与双币种流水。相同客户同一请求编号重复提交返回原结果；同编号不同参数拒绝。收到网络错误必须用原编号重试，不要新建编号；客户端会在当前浏览器标签页保存待确认编号（不保存交易密码）。不同实例共享数据库约束与行锁。
- 后台客户列表/详情可查看港币余额，手动入账按 CNY/HKD 写入相应账户，资金明细保留两条币种流水、兑换编号及成交汇率。港币与人民币不直接相加，现有人民币资产列不包含港币。
- 资金兑换不代表所有港股都以港币计价。港股模拟交易的独立开关、支持币种与报价校验见下节。
- 定向验证：`go test ./api/app/v1/open/mobile -run "TestExchange|TestCurrencyExchangeIntegration" -count=1`。设置 `EXCHANGE_TEST_DSN` 可运行隔离数据库测试，使用随机独立模式（schema），结束删除该模式，不改业务客户。

### 独立港币模拟交易

- 先执行 `go run . --migrate`，新增 `hong_kong_trade_requests` 幂等回执表。系统设置 `hkTrade.enabled` 默认关闭；需后台开启且对应证券启用后才能交易。同步新增港股证券默认启用，但不自动开启港股交易总开关。
- 客户认证接口 `GET /api/v1/open/mobile/trade/hong-kong/quote/:code` 返回五位代码、HKD 报价、实际报价时间、数据来源、每手股数、费用参数、独立港币余额及可交易状态/原因。
- `POST /api/v1/open/mobile/trade/hong-kong/orders` 接收 `request_id`、`code`、`direction`（买入/卖出）、`quantity`，每次执行前重新核对东方财富和腾讯报价，取原始报价时间较新的有效价格，相同时间优先东方财富；东方财富请求失败或无有效价格时记录告警并使用腾讯，不将请求时间当报价时间。回执含 `currency`、`quote_at`、`close_price_simulation`、成交价格/数量、各项费用及 `balance_after`。这是公开延迟报价模拟，不是真实交易所撮合。
- 腾讯扩展报价仍提供字段 60（每手股数）、63（GP 普通股）、75（HKD 币种）及盘口；缺失交易元数据时不能仅凭东方财富价格下单。字段缺失、代码不一致、无效价格/整手、非港币柜台或非普通股均拒绝。普通报价最多允许延迟 30 分钟，未来时间最多容忍 60 秒；上游字段结构变化时应重新验证，不可猜测填值。价格 `quote_at` 与腾讯盘口 `depth_at` 独立保存、展示，东方财富新价格不能延长腾讯旧盘口的有效期。
- 开启 `trade.allDay` 后，港股市价模拟在盘外可使用最近工作日 16:00（含）至 16:30（不含）的收市阶段报价：工作日当天须 16:10 后；次日 09:30 前可使用上一工作日，周末及周一开市前可使用周五。交易时段、午休及 16:00–16:10 不放宽旧报价限制。未接入完整港股节假日日历，不放行长假或停牌多日旧价。仅在超过30分钟的收市阶段报价确实被使用时返回 `close_price_simulation=true`，界面、回执、成交记录和资金流水明确标注“全天收市价模拟成交（非实时）”及原始报价时间；这不是官方收市价认证。关闭全天开关后新委托恢复正常时效校验。
- 本机收市价测试为独立例外，默认关闭：仅当 `--dev` 开发模式、请求连接和客户端均为回环地址且 `hkTrade.localCloseTest=true` 时可能生效；生产模式及远程请求一律忽略该配置。工作日香港时间 16:10 后，只允许当日 16:00 起的收市阶段报价，跨日立即失效，上午/昨日/无效/未来报价不放行。不要求修改电脑时间，也不把上游报价时间改成当前时间；它不是官方收市价认证或历史盘口回放。
- 报价接口和成交回执返回 `local_close_test`，客户端显著显示“本机收市价模拟测试（非实时成交）”、真实报价时间；成交记录及资金流水保存测试标识与原始报价时间。此模式可跳过该收市时段及30分钟时效限制，但证券启停、币种/品种、整手、费用、余额、幂等等规则均不变。关闭配置后，新委托恢复正常校验，历史回执仍可按原编号重放。
- 买入按真实每手整数倍，使用港币全额支付且杠杆固定 1 倍。买入可当日卖出，卖出按整手或全部可卖数量。默认交易时段按香港工作日 09:30–12:00、13:00–16:00 校验，未实现完整交易所节假日日历；`trade.allDay` 为 A股和港股共用的全时间段模拟交易开关，同时用于市价及限价撮合，跳过交易日/时段，另允许上述港股盘外收市价市价模拟，不跳过币种、品种、整手、费用、余额等校验。限价仍严格校验盘口时效。开关关闭后恢复各市场原有时段限制。
- 费用使用后台港股佣金/最低佣金、买卖双向印花税与其余三项交易费，按项目规则分别舍入到分。这是模拟费用规则，不宣称覆盖交易所全部税费舍入、最低额或豁免规定。
- 事务锁定客户及相关配置/证券行，原子更新港币余额、港股持仓、成交、港币流水及回执，不使用人民币余额、人民币冻结资金或人民币累计盈亏。资金不足拒绝成交；A 股管理费、自动补仓与相应自动强平查询排除港股。
- 相同客户/请求编号重复提交返回原回执，同编号不同参数拒绝。已成功回执在数据源断线、交易关闭或时段结束后仍可重放；网络结果未知时必须重试原编号，不要新建编号。客户端在当前标签页保存待确认请求。
- `/trade/positions`、`/trade/records` 默认仅查询非港股，显式传 `market=HK` 查询港股；原 A 股下单接口不接受港股。账户汇总按 CNY/HKD 分离，不直接相加。
- 后台禁止直接新增、覆盖或删除港股持仓，须通过模拟买卖或后台强平结算。后台强平使用证券缓存价格，延续原强平不扣交易费用的规则，但港股只结算到 HKD 账户；操作前应确认缓存报价。后台持仓可查询腾讯公开延迟价格，不代表实时盘口。
- 客户端持仓接口按唯一证券代码批量取价（每批最多100只）：A股和港股均并行核对腾讯与东方财富，逐只选择通过时效检查且原始时间较新的报价，同时间优先东方财富；单只某源无效不影响另一有效来源。验证代码、有限正价格及原始时间，返回 `quote_at` 和 `quote_source`，不使用证券缓存旧价覆盖新成交持仓。交易时段要求30分钟内报价，午休允许当日上午收盘前30分钟起的报价，盘外允许最近工作日收盘前30分钟起的报价，周末按上一周五处理。港股按12:00午休、16:00收盘，下午开市后不继续放宽上午旧报价。未来超过60秒、缺失或过期报价导致明确的估值不可用错误，不返回部分合计或旧价格。未接入完整节假日日历，长假或停牌多日旧价不放行。查询为只读，不改资金、持仓成本、数量或成交。公开源可能延迟，商用及行情分发前须确认授权。
- 客户端个人中心及交易持仓页统一按“可用人民币＋冻结人民币＋持仓本金＋杠杆浮盈亏”计算 A股自有总资产，港股仍按“可用港币＋冻结港币＋港股市值”独立汇总；行情读取失败不显示零持仓或旧估值。定向验证：`go test ./util/positionquote ./api/app/v1/open/mobile -count=1`。后台强平、管理费与补仓属于独立结算流程，本次只读估值修复不追溯更改历史结算。
- 新增认证只读接口 `GET /api/v1/open/mobile/trade/holdings?market=A|HK`，与估值共用当前客户、市场及未平仓过滤，只返回持仓标识、币种、代码、名称、持有/可卖数量与杠杆，不调用行情、不返回旧价或估值。其他股票估值失败不阻断当前股票买卖，数量读取失败时前端禁止使用缓存可卖量；资产合计仍要求全部持仓估值有效。市价成交及限价撮合保留当前股票取价、权限、余额和事务内可卖量校验。补充 A股原始报价时间检查：市价按现有估值时段校验，盘外全天模拟仅接受最近工作日收市阶段报价；限价撮合严格要求30分钟内盘口，旧盘口继续等待，不放宽港股原有时效规则。
- 验证：`go test ./util/hkquote ./api/app/v1/open/mobile ./api/app/v1/private/admin/platform/stock -count=1`。设置 `HK_TRADE_TEST_DSN` 可启用随机隔离 schema 的数据库回归，覆盖幂等并发、回滚、费用/港币结算、全天收市价买卖及 A 股风险任务隔离；结束删除隔离 schema，不改业务客户。连接账号须有创建/删除 schema 的权限。设置 `HK_QUOTE_LIVE_TEST=1` 可单独运行 `go test ./api/app/v1/open/mobile -run TestHongKongTradeQuoteLive -v -count=1`，只读取公开报价，不下单或写入业务数据。

#### 重点行情高频同步与异常监测

- 独立任务每5秒检查当前客户持仓、自选和最近2分钟查看/交易过的已收录证券。持仓、自选是全部客户去重后的公共证券集合，不返回任何客户信息；最近查看队列为进程内有界缓存，最多2000只，超量淘汰最久未查看的股票。详情、轻量报价和交易报价入口自动登记近期证券。
- A股与港股各按自己的交易时段运行，目标盘中约5秒、盘外/午休60秒；沿用 `stockSync.enabled` 开关，关闭后两种自动任务均停止。每市场每轮最多100只，超量按代码轮转，不只反复更新前100只；网络耗时、任务防重入和轮候可能延长每只股票的实际间隔，不承诺全市场5秒报价。
- 每轮并行核对东方财富与腾讯，逐只择最新有效价格，同时间优先东方财富。单只失败不阻断其他重点股票写入；两源都无有效价时不覆盖缓存，不改写原始时间，也不放宽30分钟时效。连续整轮失败按5、10、20、40、60秒退避，成功后恢复正常间隔。盘中原始时间延迟超过3分钟给出提示，不等同于可以放宽成交时效。
- 高频更新只改证券报价字段，不修改账户、持仓、成本和历史成交。A股全市场发布、港股全市场发布与重点任务均按报价时间防回退，避免慢任务覆盖较新行情；全市场榜单仍按原设置更新，不把榜单全部提高到5秒。
- 后台“股票信息”每5秒读取 `GET /api/v1/private/admin/platform/stock/securities/sync/priority`，分别显示两市场的最近请求/完成/下次计划、有效/缺失/延迟/轮候数量、来源计数、故障来源及部分异常代码。失败、降级和恢复写入日志，同类异常最多每分钟重复一次；任务超过下次计划45秒仍无进展时提示停滞。未配置企业微信、钉钉或短信通知。
- 客户端行情、自选、详情及交易报价携带相关证券的 `sync_warning`，不混入下单失败；恢复新价后清除该股票提示。新增轻量 `GET /api/v1/open/mobile/securities/:code/quote`，详情和A股下单面板每5秒读取价格，不重复拉取整份K线/分时。A股市价成交也按当前股票核对两源，腾讯盘口失败不再阻断有其他有效价格的市价单；限价仍须有效盘口，不能用东方财富最新价代替盘口成交。
- 状态、最近查看及防重入锁为单进程内存，服务重启重建；多实例部署需补共享队列、分布式锁和统一健康监测。公开源延迟、限流、无成交或停牌仍可能没有新价；请求完成不代表交易所产生了新成交。未接入完整节假日日历。
- 验证：`go test ./util/hkquote ./util/positionquote ./api/app/v1/private/admin/platform/stock ./api/app/v1/open/mobile ./cron -count=1`。设置 `HK_SYNC_TEST_DSN` 可运行隔离事务内的重点范围、只读状态保留和两类任务价格防回退数据库回归。

#### 港股限价委托与严格盘口模拟撮合

- 上线前执行迁移，新增客户 `hkd_frozen_balance`、限价委托可空 `request_id` 与客户/编号唯一索引、成交盘口 `quote_at`；旧 A股委托编号为空，不改变现有委托。
- `POST /api/v1/open/mobile/trade/hong-kong/limit-orders` 接收 `request_id`、五位 `code`、`direction`、正整数 `quantity`、最多三位小数 `limit_price`。这是项目模拟精度，不代表港交所价位表。相同编号/参数返回当前原委托，参数冲突拒绝；重试不依赖新行情。不得用 A股下单接口提交港股。
- 提交时读取公开行情验证港币普通股和实际每手数量，允许收市挂单；买入冻结目标价本金及预估费用，仅影响 HKD 可用/冻结余额，卖出冻结可卖股数。非整手只允许一次委托全部可卖数量。冻结/解冻保存港币流水，冻结款不能兑换或重复使用。费用提高超出原冻结额时不动用其他可用资金，保留委托并报错，须撤单重下。
- `GET /trade/limit-orders` 默认只查 A股，`market=HK` 查港股，均分页；回执附币种、冻结金额、待成交说明及成交盘口时间。`DELETE /trade/limit-orders/:id` 验证所属客户；港股重复撤单不重复解冻，已成交不能撤。停用交易后仍可撤单。
- 延续每分钟撮合任务。港股默认在香港工作日 09:30–12:00、13:00–16:00 检查有效买卖盘口，开启 `trade.allDay` 后允许非交易日/非交易时段撮合；事务内重新读取设置，关闭后恢复时段限制。全天收市价模拟及本机收市测试均不放宽限价报价有效期。盘口使用腾讯扩展报价买卖档（9–28）及独立的 `depth_at`，只接受有限正价格及正整数挂量；无效档视为无可执行盘口，不拿最新价填充。超过30分钟、无盘口、零挂量、交叉盘口、目标价未满足均保持待成交，全时间段模式也不例外；成交记录保留腾讯盘口时间，而不是东方财富价格时间。
- 买入取最低有效卖价且不高于目标价，卖出取最高有效买价且不低于目标价。延续 A股“有效档位触发整笔模拟成交”的简化模型，不模拟排队、部分成交或多客户流动性消耗；公开源常缺有效挂量，不能保证港股委托会成交，更不是实时交易所撮合。未实现完整休市日历。
- 客户行→委托行→持仓行锁定，成交、撤单竞争只允许一个结果；解冻、按盘口成交、费用、持仓、流水及成交状态在同一事务完成，失败全部回滚。成交复用独立港币结算及内部幂等回执，备注标注限价模拟和真实盘口时间。A股管理费/补仓撤单排除港股，后台强平会撤销对应卖出委托。

## 港股后台采集

证券信息页提供“一键启用港股”，确认后调用受证券菜单权限保护的 `POST /api/v1/private/admin/platform/stock/securities/enable/hong-kong`，单条数据库更新启用全部未删除且尚未启用的 `.HK` 证券，返回实际更新条数。范围不受分页或筛选影响，包含手动停用的现有港股；不修改 A股、软删除证券、行情或配置，重复执行不会重复更新已启用记录。该操作不绕过港股交易总开关、报价时效、品种及整手规则。

后台“证券列表 → 证券信息”提供手动同步港股按钮，用于新增/更新新浪证券目录并核对东方财富与腾讯报价。已收录港股另有独立自动报价任务，与A股共用“证券行情同步”的启用开关、盘中/盘外间隔和最大条数，默认盘中60秒、盘外600秒，另需采集耗时；港股按09:30–12:00、13:00–16:00判断时段，不沿用A股11:30午休、15:00收盘，也不因全天模拟交易开关而伪造真实行情。首次仍需手动同步港股目录，自动任务不依赖新浪目录接口每次可用。

港股自动更新每批100只、最多4批并发，主备报价在批内并行核对，收集后统一事务发布，沿用不回退原始报价时间的保存规则。与手动采集共用运行状态锁，不重复执行，不覆盖人工启停、持仓成本或资金。主备均失败时记录错误、保留原缓存及原始时间；单只无报价时记录缺失数量，页面可按真实时间提示延迟，不将缓存保存时间当成新报价时间。客户端行情、港股详情、自选及港币持仓/资金汇总自动检查新数据；估值或资金接口失败后不展示旧资产、旧冻结资金或旧持仓预览。

- 新浪列表接口：`https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHKStockData`。
  使用 `page=1&num=60&sort=symbol&asc=1&node=qbgg_hk&_s_r_a=init`，逐页读取直到返回空数组。不得依赖总数接口提前停止；空响应、重复代码、乱序、上游错误或超过 100 页都会终止采集。
- 腾讯报价接口：`https://qt.gtimg.cn/?q=hk00700,hk09988`，每批最多 100 只，按 GBK 解码。
- 东方财富报价接口：`https://push2delay.eastmoney.com/api/qt/ulist.np/get`，使用 `secids=116.00700,116.09988`、`fltt=2`、`fields=f12,f13,f2,f3,f5,f6,f124`，每批最多100只；`f124` 为原始报价时间，不使用本机时间替代。价格保留原始小数，缺字段、零价、未来异常时间等不作为有效报价。
- 保留五位证券代码及前导零，完整代码为 `00700.HK`，市场为“港股”、交易所为“港交所”。来源列表未明确提供板块分类，采集不推断板块，也不覆盖人工分类。
- `quote_at` 保存上游报价时间的 Unix 秒数；解析时区为香港时间。`updated_at` 仅表示数据库更新时间，两者不能混用。现有 A 股数据未补历史报价时间，显示为 `--`。
- `source=eastmoney` 表示采用东方财富报价；`sina/tencent` 表示采用腾讯报价（交易接口更新后为 `tencent`）；`sina` 表示采用新浪报价；`sina/unavailable` 表示没有有效报价。无报价新证券的 `quote_at=0`，不会使用昨收价冒充现价。任务完成后返回各来源数量，后台显示东方财富、腾讯、新浪及无报价计数。
- 在三个来源中选择时间较新的有效报价，相同时间优先东方财富。东方财富或腾讯网络、格式错误会记录告警并尝试其余来源；新浪列表失败或所有证券均无有效报价时取消写入。取消请求立即终止。完整列表通过数据库事务批量保存，任一批入库失败整体回滚；旧报价或无报价不会覆盖数据库已有的较新有效行情。
- 新增港股默认启用；重复同步不修改人工启停、软删除状态或板块。已有停用港股须手动启用或使用“一键启用港股”。采集不会删除本次列表中缺失的历史证券，不会覆盖 A 股六位证券代码的数据。
- 客户端列表通过 `market=港股` 显式读取采集来源记录（含不可交易的停用记录）；默认列表仍仅返回已启用的非港股证券。港股换手率排行明确返回未接入提示，客户端禁用该排行。报价详情仅返回缓存报价、来源和报价时间，不触发 A 股盘口或图表接口；客户端显示三位小数及成交股数单位。分时、K 线与盘口尚未开放，模拟交易走独立接口。
- 公开港股报价可能延迟约 15 分钟，不能用于实时盘口撮合；商用及行情分发前须另行确认授权。该列表不等同于已经与港交所官方全部证券品种完成对账，且暂未提供换手率。
